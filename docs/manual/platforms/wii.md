# Usage

* Launch Diablo from your Wii Homebrew Channel

## Controls

* C-Stick or D-pad: move hero, select spell
* A: select spell, back while in menus
* B: attack nearby enemies, talk to townspeople and merchants, pickup/place items in the inventory, OK while in main menu.
* Z: pickup items, open nearby chests and doors, use item in the inventory, select spell
* C: open chests and doors
* Plus + ↑: game menu(Plus + Home)
* Plus + ↓: toggle automap
* Plus + ←: character sheet (alt: ZL or Start + L)
* Plus + →: inventory (alt: ZR or Start + R)
* Wii-Mote: move automap or simulate mouse


---

Game saves and `diablo.ini` are located at the devilutionx folder

Saves are compatible with PC saves from Diablo 1 and DevilutionX.
